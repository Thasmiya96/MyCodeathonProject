# MyCodeathonProject

College Management System
--------------------------
     A desktop-based College Management System developed in Java using Swing. Built as a part of a Codeathon competition, this project focuses on streamlining college administrative tasks with a simple and intuitive graphical interface.

## ✨ Features

- 🔐 **Login System** – Secure access with user authentication.
- 🎨 **GUI Interface** – Developed using Java Swing for interactive design.
- 🧑‍🎓 **Student Management** – Add, update, and view student records.
- 👩‍🏫 **Faculty Management** – Manage faculty details efficiently.
- 🗓️ **Course & Subject Management** – Handle course structures and subjects easily.![Screenshot 2025-05-03 145543](https://github.com/user-attachments/assets/39ca49cb-6d18-4c70-ac9d-7a4a7863d029)

- 🖼️ **Image Integration** – Displays college image/logo in the UI.
- 📊 **Fee Structure Module** – Track student fees and payment status.
- 📁 **Data Storage** – Uses  database  for storing records.

## 💻 Technologies Used

- Java (JDK 11)
- Java Swing
-  Notepad (as editor)
- JDBC 
- Oracle DB
